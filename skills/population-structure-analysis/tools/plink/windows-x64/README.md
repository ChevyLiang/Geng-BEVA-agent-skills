# Windows PLINK location

For a Windows Codex deployment, place the genomic **PLINK 1.9** executable here as:

```text
plink.exe
```

Expected path:

```text
skills/population-structure-analysis/tools/plink/windows-x64/plink.exe
```

The executable is intentionally not included in this repository. The resolver validates `plink.exe --version` before use.
